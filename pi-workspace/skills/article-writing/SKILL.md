# Article Writing

## Workflow

1. Clarify audience, goal, angle, and publishing surface when missing.
2. Create a short brief with thesis, reader promise, structure, and sources needed.
3. Draft with a strong opening, useful section headings, concrete examples, and a clear ending.
4. Edit for flow, factual caution, specificity, and reduced repetition.
5. Save durable outputs under `/workspace/articles`.

## Output Files

Use descriptive filenames:

```bash
/workspace/articles/YYYY-MM-DD-topic-brief.md
/workspace/articles/YYYY-MM-DD-topic-draft.md
/workspace/articles/YYYY-MM-DD-topic-final.md
```

## Style Rules

- Prefer clear, direct prose over hype.
- Avoid generic filler and repeated claims.
- Use examples, comparisons, and specific details.
- Mark uncertain facts with `TODO: verify`.
- Do not invent sources, statistics, quotes, or named research.
